## Afspraken

- **Doorlopende documenten** (worden steeds bijgewerkt) → eigen map in `01`–`03`, één actuele versie, geen kopieën als `-nu`, `(1)` of `v2`.
- **Alles wat bij een week hoort** (notulen, agenda, sprint-Excel) → `04-Weken/<week>/Overleggen/` of `Scrum/`, bestandsnaam begint met de datum (`2026-10-01-Notulen-...`).
- **Materiaal van de docent** → `05-Lesmateriaal/Van-de-docent/`, niet aanpassen.
- Bestandsnamen zonder spaties (gebruik `-`), dan werken links in Markdown gewoon.
