# Documentatie — weekmappen

Eén map per lesweek met twee invulbare templates, gebaseerd op [`Dagelijkse-Documentatiecheck-DTI.md`](../Dagelijkse-Documentatiecheck-DTI.md). Mappen zijn genummerd zodat ze **chronologisch** sorteren in de bestandsverkenner (map- en weeknummer lopen niet gelijk op, want de lesweeknummers uit het rooster slaan week 43 en 52–53 over):

- **Dagverslagen.md** — kopieer/vul per werkdag in (Deel 2 van de documentatiecheck)
- **Weekcheck.md** — vul op vrijdag of vóór een feedback-/stakeholdersessie in (Deel 3)

Vakantieweken (43, 52–53) hebben geen map.
